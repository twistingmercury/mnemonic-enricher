## Cycle 6 - Refactor enrichment worker and finalise service interface
Date: 2026-03-20
Commit: 7bca3ef
Tag: v0.0.1-cycle06

Summary:
- Removed ClaimNextJob from the Service interface and its implementation
- Refactored Worker struct: added sub queue.Subscriber field; updated New constructor
- Replaced runWorker + sleep polling loop with subscriber-based fan-out in Run:
  - Calls w.sub.Subscribe(ctx) to get deliveries channel
  - Uses buffered semaphore of size cfg.WorkerCount to bound concurrency
  - Each delivery spawns a goroutine calling handleDelivery(drainCtx, d)
  - On shutdown: drains in-flight via drainInFlight, then calls w.sub.Close()
- Added handleDelivery: unmarshals {"job_id":"<uuid>"}, calls GetJob, MarkJobProcessing,
  ProcessJob; Ack on success, Nack(false) on any unrecoverable error
- Removed sleep method (no longer needed)
- Kept runMaintenance, doMaintenance, drainInFlight unchanged
- Updated enrichment_test.go: removed ClaimNextJob from mocks, added mockSubscriber
  implementing queue.Subscriber with configurable deliveries; rewrote all tests

- Updated server.go wireDependencies: added switch on cfg.Queue.Provider constructing
